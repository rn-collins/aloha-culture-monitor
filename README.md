# Screen Culture → Consumer Behavior

Culture Intelligence Monitor tracks film, TV, and cultural moments shaping consumer style and spending, with AI governance risk scoring. Built by RN Collins.

**Live:** https://aloha-culture-monitor.vercel.app

## Repository contents

`next.config.js`, `package-lock.json`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
